Laboratorio de bases de datos desarrollado con MySQL y Node.js para organizar y analizar información sobre las ventas de videojuegos.

La base de datos contiene cinco tablas relacionadas: game, genre, platform, publisher y game_release.

Se trabajó con 16.598 publicaciones, 11.495 videojuegos, 12 géneros, 31 plataformas y 578 empresas.

Estructura del proyecto

config/: conexión con MySQL.

data/: archivos CSV.

src/: lectura, validación y carga de datos.

sql/: estructura de las tablas y consultas SQL.
